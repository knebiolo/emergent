# Long-term Memory: Do Not Create Scripts or Tools Unnecessarily

Summary:
- The assistant must not create new scripts or tools if an existing script or tool in the repository can be used or modified to achieve the same goal.

Behavioral rule:
- When a new script or tool appears needed, present a short proposal that compares using/extending an existing script vs creating a new one, and obtain explicit approval before creating the new script.
